# Waste2Watt — Project Blueprint

This bundle's authoritative project definition is in `PROJECT_BRIEF.md`, with implementation rules in `AGENTS.md`, technical details in `ARCHITECTURE.md` and `AI_SYSTEM.md`, visual guidance in `DESIGN_SYSTEM.md`, and the copy-ready prompt in `ANTIGRAVITY_START_PROMPT.md`.

## Positioning
Waste2Watt is an explainable waste-to-energy decision intelligence platform for institutions. AI interprets and orchestrates; deterministic tools calculate; evidence and uncertainty remain visible.

## Build order
Repository reconnaissance → product shell → deterministic domain engine → API/persistence → Bedrock tool-using analysis → scenario economics → AWS deployment → demo.
