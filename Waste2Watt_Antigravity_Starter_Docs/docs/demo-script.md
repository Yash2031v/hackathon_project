# Three-minute Demo Script

## 0:00–0:20 — The problem
“Institutions generate organic waste, but they often cannot tell which treatment route is appropriate or whether energy recovery is feasible.”

## 0:20–0:45 — Record the waste
Add a clearly labelled demo record from a college canteen. Show mass, waste type, date and data provenance.

## 0:45–1:25 — Run Waste Intelligence
Run the analysis. Show the pathway shortlist, the reasons, missing inputs and evidence. Emphasise that the AI orchestrates and explains; deterministic tools calculate the numbers.

## 1:25–2:05 — Compare scenarios
Open anaerobic digestion and compare with another suitable pathway. Change an assumption and show how the result changes. Show estimated vs measured labels.

## 2:05–2:35 — Prove the technology
Show the actual API request, Lambda logs/CloudWatch or the AWS architecture path. Only show real services and real requests that were tested.

## 2:35–3:00 — Close
“Waste2Watt helps institutions move from waste logs to evidence-backed decisions. It does not promise energy production; it helps users understand the potential, the uncertainty and what to verify next.”

## Recording checklist
- Keep the video under 3 minutes.
- Make the public/unlisted link accessible while signed out.
- Demonstrate the features that really work; don't narrate unimplemented features as completed.
- Show where AWS fits in the actual running application.
- Mention AI coding tools and credit third-party assets as required by the rules.
