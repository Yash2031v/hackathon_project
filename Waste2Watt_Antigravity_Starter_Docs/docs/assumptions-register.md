# Assumptions Register

Maintain this file whenever a new factor or model assumption is introduced.

| ID | Assumption / factor | Unit | Source | Status | Owner / next action |
|---|---|---|---|---|---|
| A-001 | Feedstock-specific biogas yield | m³/kg or documented basis | To be selected from a credible source | Missing | Find and cite a suitable technical source |
| A-002 | Methane fraction | fraction or % | To be selected from a credible source | Missing | Configure with source and date |
| A-003 | Electrical conversion efficiency | fraction or % | Equipment-specific source/quote | Missing | Do not invent; configure only for a scenario |
| A-004 | Electricity tariff | currency/kWh | Institution's actual tariff | User-configured | Let user enter value |
| A-005 | Capex and annual opex | currency | Local quotation or clearly labelled scenario assumption | Missing | Do not present as a market quote |
| A-006 | Avoided emissions factor | kg CO₂e/kWh or appropriate basis | Credible, region-appropriate source | Missing | Optional; do not claim carbon savings until configured |

Rule: the product must not calculate a definitive result from missing factors. A demo-only factor must be clearly labelled as illustrative.
